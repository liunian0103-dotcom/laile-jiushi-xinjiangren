# 来了就是新疆人

下班了，轮到你出发。选择一位原创打工人，在新疆五站弹射突围。

[打开游戏](https://liunian0103-dotcom.github.io/laile-jiushi-xinjiangren/)

## 怎么玩

选择角色，进入当前站；拖动瞄准，松手发射。清空障碍即可过关，障碍越过底线会扣除体力，人物下方的进度条显示剩余体力。击破技能箱，在回合结束时选择强化。弹珠全部发出后，可点击“快速收球”或按 R 缩短等待；收球仍会正常结算并下压障碍。空格发射，Esc 暂停。

三个角色各有优势与代价：陈序每站抵挡一次越线伤害、弹珠伤害降低10%；陆骁初始穿透一块障碍、初始两颗弹珠；林晚每站首个技能箱多学一次、初始两颗弹珠。

五站依次为国际大巴扎、那拉提草原、赛里木湖、喀什古城、火焰山。手机横屏视野更大，也可直接开始。浏览器支持时可点击“全屏”；方向检测不会阻止游玩。

## 通关礼遇

五站分别奖励100、150、200、250、300旅行积分。同一局同一关不会重复发奖。积分可兑换四种新疆特产演示券。

**这是演示商城，商家为虚拟设定，优惠券不可实际消费，不代表已达成合作。** 钱包保存在当前浏览器本地，不跨设备同步；清理网站数据会清空钱包。退出本局返回首页会结束当前旅程，已保存的积分与券保留。

## 开发理念与后续方向

用打工人角色建立代入感，用清楚的弹射反馈提供短时放松，用新疆场景形成地方记忆，再让通关奖励延伸到旅行礼遇。界面坚持一屏一个重点，商城不打断战斗。

未来拟与文旅活动、景区或商业街区、特产品牌探索主题活动制作与运营服务；真实核销和订单能够验证后，再考虑按有效成交分成。当前没有真实商家接入、交易、核销或收入验证。
